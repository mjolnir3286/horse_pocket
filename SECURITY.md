# Security Policy

## Reporting a vulnerability

Please report security issues privately using **Report a vulnerability** on this repository's Security tab. Do not open a public issue, and do not send reports to a personal email address.

We will acknowledge your report and let you know when a fix is available.

## Scope

Horse Pocket's apps run locally in your browser. Saved data stays on your device. This policy covers the apps in this repository (the portal, Couch, Wad, Shed, and the Couch relay Worker), their published GitHub Pages builds, and this repository's GitHub Actions workflows.

Out of scope: third-party APIs the apps call (such as TVmaze, TMDB, or Open Library), and issues in your own browser or device.
